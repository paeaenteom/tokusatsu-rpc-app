トレイ常駐メモリを 315MB から 171MB に減らし、画像の表示を速くしました。

## インストール

下の **`TOKU-RPC-Setup-0.2.5-beta.exe`** ひとつだけダウンロードして実行してください。
アプリとブラウザ拡張機能がまとめてインストールされます。ほかにダウンロードするファイルはありません。

- インストール画面で **拡張機能を入れるブラウザにチェックを入れる**だけです
  (Chrome · Edge · NAVER Whale · Brave · Vivaldi)
- 拡張機能を登録するときに **ユーザー アカウント制御 (UAC) のダイアログが一度だけ**表示されます → **[はい]**
  (Windows が拡張機能のポリシー領域への書き込みを管理者にしか許可していないためです。アプリ本体は自分のアカウントのフォルダにインストールされます)
- インストールが終わったら **ブラウザを完全に終了してから起動し直してください**
  (トレイアイコンからも終了させないと拡張機能が反映されません)

## 0.2.5 での変更

### メモリ
- **トレイ常駐 315MB → 171MB**
  - ウィンドウを閉じると描画用のプロセスを実際に破棄します。以前は隠すだけで、
    トレイにいる間もずっと保持していました (実測 95MB)
  - 開き直すとその場で作り直します。速度と動作は変わりません
- 画像の元データをサイトの数だけ重複保持していたのを 1 つにまとめました

### 画像が速く出ます
- **同じ画像を 3 回アップロードしていたのを 1 回に** (サイトごとの接続が別々に上げていました)
- 合成画像を PNG ではなく JPEG で送ります (透明部分が無いので PNG は不要でした)。
  容量は約 1/4
- 画像の取得順を修正しました。必ず失敗する経路を先に試してから成功する方へ回っており、
  その無駄足がそのまま待ち時間でした

### Disney+
- **一覧・コレクションページでも作品ロゴ**を表示します (作品ページのみだったのを拡大)
- 背景アートワークを高解像度で取得します (400x225 → 1920x1080)。
  一部のページではそもそも取得できていませんでした

### 整理
- 使われなくなったアップロード経路を削除しました (動作の変化はありません)

## 0.2.4 での変更

### Disney+ の作品ページがページそのままの見た目に

## 0.2.3 での変更

### サムネイルが見切れなくなりました
- Discord は大きい画像を**正方形に切り取って**描きます → 16:9 のサムネイルは
  左右 43% が失われ、中央だけが残っていました
- これからは元の画像を丸ごと正方形に収めて送ります (上下の余白は透明)
  → **TTFC・IMAGINATION・Disney+ すべて**画面のまま表示されます

### 反応速度 — ほぼ即時
- 変化があれば**待たずにすぐ**反映します
  - 以前は変化のたびに 0.5 秒 (閲覧中は 1 秒) を必ず待っていました。
    **ブースターを入れても体感が変わらなかった原因がこれです** —
    拡張機能だけ速くなり、アプリが毎回同じ時間を足し直していました
  - Discord の制限 (20 秒に 5 回) は今まで通り守ります。連打時だけ間隔を空けます
- Disney+ の再生/一時停止をプレーヤーのイベントで即座に取得します (以前は最大 0.4 秒遅れ)
- ブースターは安全網の役割になりました。切ってもほとんど変わらず、CPU を節約できます

### 修正
- **タブを閉じてもステータスが残る問題** — タブを閉じる処理が存在しない変数を読んで
  停止し、よりによって「消すべきそのとき」だけ通知が出ませんでした
  - 再接続時に閉じたタブの情報が復活する問題も直しました
  - アプリ側の安全網を追加: 拡張機能からの連絡が 5 分途絶えると自ら片付けます
- **ひとつのサイトを閉じると他のサイトまで消えていた問題**
- **消えたあと同じ画面に戻っても再表示されない問題** (一時停止中)

### Disney+
- 作品ページでその作品の**ロゴ**を表示します (ロゴがない場合は背景アートワーク)

## 主な機能

- 視聴中に **作品名・エピソード・経過時間・サムネイル**を Discord に表示
- 見ているサイトに応じて Discord アプリケーションを自動で切り替え
  (TTFC / IMAGINATION / Disney+)
- **一気見モード** — 動画を最後まで見ると自動で次の話へ、全画面も維持
  - 一時停止しても一気見は終わりません
- 一気見の記録を Discord のウェブフックで送信 *(任意 — README 参照)*
- PC の起動時にトレイに自動で常駐
- **한국어 · English · 日本語** — 初期値はシステムの言語
  - アプリはミニウィンドウ、拡張機能はポップアップで変更。拡張機能はアプリに追従します
  - Discord に表示される文言と一気見の記録も同じ言語になります

## ファイルについて

## 注意点

- Windows 専用です
- 署名されていないプログラムなので SmartScreen の警告が出ることがあります
  → *詳細情報 → 実行*
- インストールログは `%TEMP%\toku-rpc-install.log` に残ります (問題が起きたらこのファイルを確認してください)
- このツールは視聴情報を表示するだけで、動画をダウンロードしたり著作権保護を回避したりはしません
