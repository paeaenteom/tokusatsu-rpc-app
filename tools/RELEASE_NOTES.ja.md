Disney+ 対応と多言語が入り、待機中のメモリを大きく減らしました。

## インストール

下の **`TOKU-RPC-Setup-0.2.0-beta.exe`** ひとつだけダウンロードして実行してください。
アプリとブラウザ拡張機能がまとめてインストールされます。ほかにダウンロードするファイルはありません。

- インストール画面で **拡張機能を入れるブラウザにチェックを入れる**だけです
  (Chrome · Edge · NAVER Whale · Brave · Vivaldi)
- 拡張機能を登録するときに **ユーザー アカウント制御 (UAC) のダイアログが一度だけ**表示されます → **[はい]**
  (Windows が拡張機能のポリシー領域への書き込みを管理者にしか許可していないためです。アプリ本体は自分のアカウントのフォルダにインストールされます)
- インストールが終わったら **ブラウザを完全に終了してから起動し直してください**
  (トレイアイコンからも終了させないと拡張機能が反映されません)

## 0.2 での変更

### Disney+ 対応 *(実験)*
- 作品名・シーズン/話数・エピソード名・経過時間・**エピソードのサムネイル**を表示
- ブランドページ (Disney · PIXAR · MARVEL · STAR WARS · National Geographic) にも対応
- まだ検証中のため専用の Discord アプリケーションを使います。ここで問題が起きても
  TTFC・IMAGINATION の表示には影響しません

### 複数のサイトを同時に表示
- これまでは複数開いてもひとつしか表示されず、どれを出すか決めきれずちらついていました
- 開いているサイトがすべてプロフィールに並びます。同じサイトを複数タブで開いたときの
  ちらつき防止はそのままです

### メモリと反応速度
- トレイ常駐中のメモリが **310MB → 177MB**。ウィンドウを開くまで作らないようにしました
- ウィンドウを閉じている間の毎秒の再描画とログ送信を止めます。開けばすぐ最新になります
- 状態が変わったら次の周期を待たずに Discord へ反映します

### そのほか
- タスクバーのアイコンが Electron の既定アイコンになっていた問題を修正
- トレイアイコンが潰れて見えた問題を修正 (その大きさ用のアイコンを使うように)
- 韓国語でホーム画面が Discord に何も表示されなかった問題を修正
  (Discord は 2 文字未満の文言を受け付けません)

## 主な機能

- 視聴中に **作品名・エピソード・経過時間・サムネイル**を Discord に表示
- 見ているサイトに応じて Discord アプリケーションを自動で切り替え
  (TTFC / IMAGINATION / Disney+)
- **一気見モード** — 動画を最後まで見ると自動で次の話へ、全画面も維持
  - 一時停止しても一気見は終わりません
- 一気見の記録を Discord のウェブフックで送信 *(任意 — README 参照)*
- PC の起動時にトレイに自動で常駐
- **한국어 · English · 日本語** — 初期値はシステムの言語
  - アプリはミニウィンドウ、拡張機能はポップアップで変更。拡張機能はアプリに追従します
  - Discord に表示される文言と一気見の記録も同じ言語になります

## ファイルについて

| ファイル | 説明 |
|---|---|
| `TOKU-RPC-Setup-0.2.0-beta.exe` | **これだけダウンロードすれば OK です** (アプリ同梱) |
| `toku-rpc-extension.crx`, `update.xml` | 拡張機能の自動インストール・アップデート用 — ブラウザが自動で取得します |
| `toku-rpc-extension.zip` | 拡張機能の手動インストール用 (自動で入らないときだけ) |

## 注意点

- Windows 専用です
- 署名されていないプログラムなので SmartScreen の警告が出ることがあります
  → *詳細情報 → 実行*
- インストールログは `%TEMP%\toku-rpc-install.log` に残ります (問題が起きたらこのファイルを確認してください)
- このツールは視聴情報を表示するだけで、動画をダウンロードしたり著作権保護を回避したりはしません
