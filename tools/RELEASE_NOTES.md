특촬 시청 정보를 Discord에 표시하고 정주행을 기록하는 도구의 첫 베타입니다.

## 설치

아래 **`TOKU-RPC-Setup-0.1.0-beta.exe`** 하나만 받아서 실행하세요.
앱과 브라우저 확장이 한 번에 설치됩니다. 추가로 받을 파일은 없습니다.

- 설치 창에서 **확장을 넣을 브라우저를 골라** 체크하면 됩니다
  (Chrome · Edge · 네이버 웨일 · Brave · Vivaldi)
- 확장을 등록할 때 **관리자 승인 창이 한 번** 뜹니다 → **[예]**
  (Windows가 확장 정책 영역을 관리자에게만 열어둬서 그렇습니다. 앱 자체는 내 계정 폴더에 설치됩니다)
- 설치가 끝나면 **브라우저를 완전히 종료했다가 다시 켜주세요**
  (트레이 아이콘까지 닫아야 확장이 적용됩니다)

## 주요 기능

- 시청 중 **작품명 · 에피소드 · 진행 시간 · 썸네일**을 Discord에 표시
- 보는 사이트에 따라 Discord 앱 자동 전환 (TTFC / IMAGINATION)
- **정주행 모드** — 영상을 끝까지 보면 자동으로 다음 화, 전체화면도 유지
  - 일시정지로는 정주행이 끝나지 않습니다
- 정주행 기록을 Discord 웹훅으로 전송 *(선택 — README 참고)*
- 부팅 시 트레이에 자동 상주

## 알아둘 점

- Windows 전용입니다
- 서명되지 않은 프로그램이라 SmartScreen 경고가 뜰 수 있습니다
  → *추가 정보 → 실행*
- 설치 기록은 `%TEMP%\toku-rpc-install.log` 에 남습니다 (문제 생기면 이 파일을 확인)
- 이 도구는 시청 정보를 표시할 뿐, 영상을 내려받거나 저작권 보호를 우회하지 않습니다
