## 백신이 "바이러스가 발견됨" 이라고 할 때

**오탐입니다.** 코드 서명 인증서를 사지 않은 개인 개발자의 설치 프로그램에서 흔히 일어납니다.

Windows Defender 가 붙이는 이름은 `Trojan:Win32/Sabsik.EN.B!ml` 인데, 끝의 **`!ml` 은
"머신러닝이 추측했다"** 는 뜻입니다. 실제로 알려진 악성코드와 일치해서가 아니라,
*서명이 없고 · 압축을 스스로 풀고 · 레지스트리를 건드리고 · 관리자 권한을 요청하는*
조합이 통계적으로 수상해 보인다는 판정입니다. 설치 프로그램이라면 원래 다 하는 일입니다.

**믿기 어렵다면 안 받으셔도 됩니다.** 대신 이렇게 확인하거나 우회할 수 있습니다.

- **소스가 전부 공개돼 있습니다** — [저장소](https://github.com/paeaenteom/tokusatsu-rpc-app)에서
  설치 프로그램 코드(`tools/installer/Installer.cs`)까지 그대로 읽을 수 있습니다
- **압축본을 받으세요** — `TOKU-RPC-<버전>-portable.zip` 은 실행 파일이 아니라 이 판정을 타지 않습니다.
  풀고 `TOKU RPC.exe` 를 실행하면 됩니다 (확장은 `toku-rpc-extension.zip` 으로 수동 등록)
- **Microsoft 에 오탐 신고** — [여기](https://www.microsoft.com/en-us/wdsi/filesubmission)에
  파일을 올리면 보통 며칠 안에 해제됩니다

서명 인증서를 마련하면 근본적으로 해결됩니다. 개인 프로젝트라 아직 없습니다.

### "스마트 앱 컨트롤" 이 차단할 때

이건 앞의 백신 오탐과 **다른 문제**이고, 지금으로선 우회할 방법이 없습니다.

스마트 앱 컨트롤(Windows 11 전용)은 **서명이 없는 실행 파일을 조건 없이 막습니다.**
평판이 쌓여도, 파일 정보를 아무리 채워도 통과하지 못합니다. Microsoft 신뢰 루트 CA 가
발급한 코드 서명 인증서로 서명된 프로그램만 열어 줍니다.

이 프로그램에는 그 인증서가 없습니다. 인증서는 개인이 사기엔 값이 만만치 않고
(연 30만원대~), Microsoft 가 권장하는 저렴한 대안인 Azure Artifact Signing 은
**개인 개발자 가입이 미국·캐나다 거주자로 제한**돼 있습니다.

선택지는 두 가지뿐입니다.

- **설치하지 않는다** — 가장 안전한 선택이고, 그래도 괜찮습니다
- **스마트 앱 컨트롤을 끈다** — *Windows 보안 → 앱 및 브라우저 제어 → 스마트 앱 컨트롤*
  ⚠ **한 번 끄면 Windows 를 다시 설치하기 전까지 켤 수 없습니다.** 이 프로그램 하나 때문에
  시스템 전체의 보호를 영구히 내리는 셈이니, 그만한 가치가 있는지 꼭 따져 보세요.
  [소스가 전부 공개돼 있으니](https://github.com/paeaenteom/tokusatsu-rpc-app) 직접 읽어 보고 판단하셔도 됩니다.

인증서를 마련하면 바로 서명해서 올릴 예정입니다.
