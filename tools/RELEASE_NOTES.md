디즈니+ 지원과 다국어가 들어갔고, 평소 메모리를 크게 줄였습니다.

## 설치

아래 **`TOKU-RPC-Setup-0.2.0-beta.exe`** 하나만 받아서 실행하세요.
앱과 브라우저 확장이 한 번에 설치됩니다. 추가로 받을 파일은 없습니다.

- 설치 창에서 **확장을 넣을 브라우저를 골라** 체크하면 됩니다
  (Chrome · Edge · 네이버 웨일 · Brave · Vivaldi)
- 확장을 등록할 때 **관리자 승인 창이 한 번** 뜹니다 → **[예]**
  (Windows가 확장 정책 영역을 관리자에게만 열어둬서 그렇습니다. 앱 자체는 내 계정 폴더에 설치됩니다)
- 설치가 끝나면 **브라우저를 완전히 종료했다가 다시 켜주세요**
  (트레이 아이콘까지 닫아야 확장이 적용됩니다)

## 0.2 에서 달라진 것

### 디즈니+ 지원 *(실험)*
- 작품명 · 시즌/회차 · 에피소드 제목 · 경과 시간 · **에피소드 썸네일**을 표시
- 브랜드 페이지(Disney · PIXAR · MARVEL · STAR WARS · National Geographic)도 각각 표시
- 아직 검증 중이라 전용 Discord 애플리케이션을 씁니다 — 여기서 문제가 생겨도
  TTFC · IMAGINATION 표시에는 영향이 없습니다

### 여러 사이트를 동시에 표시
- 예전에는 여러 사이트를 켜도 한 번에 하나만 떴고 어느 쪽을 보여줄지 정하느라 깜빡였습니다
- 이제 켜 둔 사이트가 전부 프로필에 뜹니다. 같은 사이트를 여러 탭에서 연 경우의
  깜빡임 방지는 그대로입니다

### 메모리 · 반응 속도
- 트레이 상주 중 메모리 **310MB → 177MB** (창을 열기 전까지 창을 아예 만들지 않습니다)
- 창을 닫아둔 동안 돌던 초당 화면 갱신과 로그 전송을 멈춥니다. 창을 열면 즉시 최신이 됩니다
- 상태가 바뀌면 다음 주기를 기다리지 않고 바로 Discord에 반영합니다

### 그 밖에
- 작업표시줄 아이콘이 Electron 기본 아이콘으로 나가던 문제 수정
- 트레이 아이콘이 뭉개지던 문제 수정 (전용 아이콘을 쓰도록)
- 한국어에서 홈 화면이 Discord에 아무것도 안 뜨던 문제 수정
  (Discord는 두 글자 미만 문구를 거부합니다)

## 주요 기능

- 시청 중 **작품명 · 에피소드 · 진행 시간 · 썸네일**을 Discord에 표시
- 보는 사이트에 따라 Discord 앱 자동 전환 (TTFC / IMAGINATION / Disney+)
- **정주행 모드** — 영상을 끝까지 보면 자동으로 다음 화, 전체화면도 유지
  - 일시정지로는 정주행이 끝나지 않습니다
- 정주행 기록을 Discord 웹훅으로 전송 *(선택 — README 참고)*
- 부팅 시 트레이에 자동 상주
- **한국어 · English · 日本語** — 기본값은 시스템 언어
  - 앱은 미니 창, 확장은 팝업에서 바꿉니다. 확장은 앱에서 고른 언어를 따라갑니다
  - Discord에 표시되는 문구와 정주행 기록도 같은 언어로 나갑니다

## 알아둘 점

- Windows 전용입니다
- 서명되지 않은 프로그램이라 SmartScreen 경고가 뜰 수 있습니다
  → *추가 정보 → 실행*
- 설치 기록은 `%TEMP%\toku-rpc-install.log` 에 남습니다 (문제 생기면 이 파일을 확인)
- 이 도구는 시청 정보를 표시할 뿐, 영상을 내려받거나 저작권 보호를 우회하지 않습니다
